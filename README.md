# Рост — личный трекер

Установка на iPhone (бесплатно, ~5 минут):
1. Создайте репозиторий на github.com, загрузите сюда все файлы из архива (кроме этого README — по желанию).
2. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root). Через пару минут появится адрес вида https://ваш-ник.github.io/репозиторий/.
3. Откройте адрес в Safari на iPhone → «Поделиться» → «На экран Домой».

Данные хранятся только на телефоне (localStorage). Раз в пару недель: Прогресс → Данные → Экспорт, и сохраните текст в заметки.
Тесты формул: `node tests/core.test.js`.

## Обновление
Загрузите новые файлы тем же способом (Add file → Upload files), замените старые, Commit changes. Перезапустите приложение на телефоне (смахнуть вверх, открыть заново). Данные не пропадут.

## Что умеет
- **Сегодня:** кольцо оптимальности, токены, что наверстать сегодня, предупреждения (боль, перегруз), краткий разбор недели.
- **Тренировка:** разминка и заминка, отметки подходов («Отметить все» одним нажатием), запас повторов, отдых между подходами, таймер отдыха, подсказки по усложнению, самочувствие и заметки. Итог тренировки (подходы, повторы, рекорды, время, потенциал дня) открывается сам, когда выполнен весь план, и по кнопке. В дни отдыха — мобильность плеч.
- **План:** прогноз токенов на 7 дней по выбранным типам дней, разгрузочная неделя, расписание по умолчанию.
- **Питание:** продукты, поиск по штрихкоду (ввод номера, база Open Food Facts), шаблоны приёмов пищи, быстрый ввод (в процентах от цели), цели по калориям, углеводам и жирам с учётом дня тренировки или отдыха, копирование со вчера, сон и вес.
- **Прогресс:** разбор недели, тепловая карта 12 недель, график веса, сверка модели с замерами, связь сна с силой, динамика упражнений, оценка расхода калорий, экспорт/импорт.
- **Отмена действий:** после любого изменения появляется «Отменить» (до 40 шагов назад; также на вкладке «Прогресс»). Вибро-отклик на нажатия можно выключить там же.

Тесты формул: `node tests/core.test.js`.
